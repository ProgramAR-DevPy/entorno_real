# Rodilla en calma

Landing page educativa en español que traduce un informe de resonancia magnética de rodilla derecha a información clara sobre cuidados iniciales, movimientos que conviene evitar, señales de alarma y preparación para la consulta médica.

## Contenidos de la pagina web.

La página organiza los hallazgos informados:

- Rotura completa del ligamento cruzado anterior (LCA).
- Rotura del cuerno posterior del menisco interno.
- Protrusión posterior del menisco externo.
- Lesión contusiva en el platillo tibial externo.

También incluye:

- Cuidados inmediatos organizados por etapas.
- Señales que requieren atención médica urgente.
- Chequeo interactivo de síntomas.
- Preguntas sugeridas para traumatología o medicina deportiva.
- Descarga de una guía de preparación para la consulta.
- Diseño adaptable a computadoras, tablets y teléfonos.

## Cómo abrir el proyecto

No requiere instalación ni compilación. Se puede abrir `index.html` directamente en un navegador.

Para ejecutarlo mediante un servidor local:

```powershell
python -m http.server 4173
```

Luego visitar:

```text
http://localhost:4173
```

## Funcionalidades interactivas

- Pestañas para navegar entre cuidados inmediatos, cotidianos y acciones que deben evitarse.
- Modal con el aviso médico.
- Chequeo de señales de alarma con resultado dinámico.
- Generación local de una guía de consulta en formato `.txt`.
- Animaciones suaves al recorrer las secciones.

## Aviso médico

El sitio tiene fines exclusivamente educativos. Organiza información a partir del informe proporcionado, pero no confirma diagnósticos, no prescribe medicamentos y no reemplaza el examen físico ni la evaluación de un profesional.

Las decisiones sobre carga, ejercicios, fisioterapia, uso de rodillera, muletas, tratamiento conservador o cirugía deben tomarse con un especialista en traumatología o medicina deportiva.

Ante dolor intenso, incapacidad para apoyar peso, bloqueo de la rodilla, hinchazón progresiva, fiebre, enrojecimiento, calor local o alteraciones de sensibilidad y coloración del pie, se debe buscar atención médica urgente.
